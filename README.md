# KaineMod

KaineMod 是面向《Left 4 Dead 2》对抗模式服务器的自定义比赛配置，基于本仓库原有的 ZoneMod 玩法调整并独立维护。原生 ZoneMod 配置单独保留并更新到 2.9.2b，KaineMod 的后续改动不会覆盖原生配置。

## 模式

- 4v4：`kainemod`
- 3v3：`kaine3v3`
- 2v2：`kaine2v2`
- 1v1：`kaine1v1`
- Quad：`kaine4K`

## 生还者行为

- 生还者倒地后，队友将其救起时，KaineMod 会根据救起前剩余的倒地血量，决定其起身后的初始临时血量：倒地血量越少，起身后获得的临时血量越低，且扣除速度**先快后慢**
  
  - 倒地血量达到 285 或以上：救起后获得 45 点临时血量。
  - 倒地血量低于 285：临时血量按剩余倒地血量递增，最低为 20 点。
  - 倒地血量越少，救起后的临时血量越接近 20 点；倒地血量越多，临时血量越接近 45 点，
  - 挂边救起不受影响。

  救起后的临时血量仍按游戏原有机制随时间衰减。

## 枪械相关

- MP5 与普通冲锋枪、消音冲锋枪共用冲锋枪组上限 3，且mp5会自然刷新
- 木狙鸟狙栓狙AWP共用狙击枪组上限 1。
- 五种 KaineMod 模式的 Magnum 持有上限为 2，Hunter 上限为 2；Quad 使用独立规则配置。
- 各人数模式使用对应的 KaineMod 配置；Quad 保留独立的 Quad 规则。
- 倒地时保留 Magnum；倒地期间散布参数乘以 1.25、射击间隔乘以 1.2，起身后立即恢复。伤害和距离衰减不变。

## 关卡流程

- 所有机关尸潮都是有限尸潮，参考了l4d2_kaine_finite_hordes插件的机关尸潮逻辑，特定关卡的机关尸潮有特定的数量，且在原版基础上适度增加（参考applemod的参数），若关卡没有参数，则默认值是150只
- witch为可选项，
- 全模式启用双hunter，感受来自双hunter的狂野吧！

## 枪械数据

枪械设计参考了1.9.3版本的思路：uzi与smg的特点都很明显，前者远距离火力，后者中远距离爆发，作为新武器的Mp5则介于两者之间，十分中正，后续有待加强

狙击枪的设计思路是：木狙/军狙伤害低，射速慢，适合点石头，远距离救人，充当稳妥的支援位；Scout/awp伤害高，射速快，适合会玩的清特感，提升防控的上限，充当高风险的输出位

作者由于不打喷子，所以霰弹枪的改动不多，如有需要可以自行修改配置文件

Uzi的准度极高，对应的伤害也很低，双枪的射速也是很高的，适合长距离点克，救人（明眼人应该能看出来作者偏好三号位/机枪）  

对应的Smg(MAC-10)的弹丸伤害也极高，但是散布更低，适合中远距离火力爆发，例如室内克集火

霰弹枪的“伤害×弹丸数”表示单发每颗弹丸伤害与弹丸数，不会改就用zonemod2.9.2b的参数了

木狙另设射击间隔 0.40 秒、对 Tank 伤害倍率 0.75；军狙对 Tank 伤害倍率 0.5。

### 枪械组上限

限制插件统计当前存活生还者持有的对应武器总数。“未设置”表示该人数配置没有为该组添加数量限制。

| 武器组                                   | KaineMod 4v4 / Quad | KaineMod 3v3 / 2v2 | KaineMod 1v1 |
| ---------------------------------------- | ------------------: | -----------------: | -----------: |
| 普通、消音冲锋枪与 MP5                   |                   3 |                  3 |            3 |
| 木泵动与 Chrome 霰弹枪                   |                   3 |             未设置 |       未设置 |
| 马格南                                   |                   2 |                  2 |            2 |
| 猎枪、军用狙击枪、Scout 与 AWP           |                   1 |                  1 |            1 |
| 自动霰弹枪、SPAS、步枪、榴弹发射器与 M60 |           禁用（0） |             未设置 |       未设置 |

Quad 使用独立武器参数：冲锋枪装填时间为 1.8 秒；木泵动霰弹枪伤害为 17、弹丸为 16。详见 `cfg/cfgogl/kaine4K/shared_settings.cfg`。
